## Explicit boundaries

- Preview choices are UI state. They do not modify pack JSON, create temporary pack overrides, select a replacement engine, or authorize native preview output.
- Partial reference reports never authorize rename/move/delete. The closed source-bound schema now covers dimensions, regions, biomes, structures, pools, pieces, generators, expressions, image-maps and blocks, with 150 class models, 75 enums and the string-adapted MantleFlag interface. Five additional read-only owner families (loot, spawners, entities, markers and mods) and 73 annotated snippet kinds participate in reference scanning without gaining field/file-operation editing authority. Only the exact root Schema.json string-array ordering format is recognized as nonreference metadata. Objects/images are supported targets. Unrecognized JSON owners, unknown fields, unsupported shapes, malformed/limited JSON and exceeded budgets block operations. The lexical inventory includes package-private fields and inherited declarations, and rejects ambiguous initialization/field forms. It is not a complete Iris schema or a grant of additional editable controls.
- Typed links include dimension region/focus/stack links, biome pools/children/carving/generators, nested object/structure/material/noise references and unambiguous categorical image-map biome/region targets. Binding resource keys are distinct from named mask binding keys. Namespaced vanilla states, state/tile/NBT maps and native surface-block labels are preserved. Omitted generator/palette/layer/hydrology defaults and null/blank generator fallbacks participate without inserting settings; affected operations block. Legacy none sentinels remain inactive, and replacements cannot acquire sentinel meaning. Canonical exact region filters now follow file operations while alias collapse and new comparison captures are blocked. Unambiguous floating carving fallback links are maintained after collecting native entry-ID precedence; source/replacement ID collisions stay guarded. Quiet block aliases support the literal string null, while uncertain affected reserved-name bindings block. Mixed/unbound categorical uses and remaining object-collision/prefix/deposit/modification selectors retain their guards. Typed snippet indirection strings retain their original bytes; shared payload references are scanned and rewritten once. Missing, unknown-kind, invalid-shape, unsafe-path, cyclic, over-depth or over-budget snippet dependencies block mutation. See [resource-operation coverage](RESOURCE-OPERATIONS.md) for the exact boundaries.
- Field coverage is source metadata. Its generated nested/inherited type graph now covers all class models in the shared catalog, including read-only owners and typed snippets. The JSON source browser resolves declared array/object paths, inherits containing-field restrictions and keeps map members/unknown data read-only. No metadata classification authorizes writes, enables an unsupported context or validates native generation. The 29 modification-recipe fields remain explicitly unclassified.
- Resource Apply changes only memory. Save preflights all planned writes/removals, publishes destinations and reference rewrites, then removes baseline/identity-bound old regular files without recursive deletion. Partial-save progress remains explicit and retryable. Pending removal state retains hashes, never old file bytes. Save Copy/As/ZIP use the current graph; fresh-folder adoption leaves the former folder intact.
- Full rendered preview output, camera/mesh/model/texture rendering, fidelity checks and engine-output rendering comparison belong to the renderer stage after UI completion.
- No backup, autosave recovery, crash recovery or disk file-history feature is authorized.
